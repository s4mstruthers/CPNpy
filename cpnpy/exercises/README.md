# CPNpy demo exercises

Each folder with a `question.md` is an exercise. Click it in CPNpy's sidebar:
the question appears beside the canvas, the given net or log is loaded, and
analysis results stay hidden until you reveal them. Press **Check** when you
are done.

Files an exercise folder can have:

| File | Role |
|---|---|
| `question.md` (or `.pdf` / `.png`) | The question. |
| `net.pnml` | A given net. Your edits go to `my answer.pnml`; this file stays as it is. |
| `log.xes`, `log.csv` or `log.txt` | A given log (`log.txt` in textbook notation). |
| `ts.txt` | A given transition system, as `s0 -a-> s1`. |
| `answer.pnml` | A model answer: Check compares your net with it on behaviour. |
| `answer.md` | A worked answer, hidden until you ask for it. |
| `my answer.pnml` | Your work, made by CPNpy the first time you edit. |

Make your own by copying a folder and changing its files.
